## 📖 About

A professional barbershop website featuring an elegant dark theme with gold and green accents. Developed using Vanilla JavaScript, it includes a dynamic image slider, a responsive gallery, a service price table, and premium UI/UX elements.

**Live Demo**: [View Website](https://p-devp.github.io/Barbearia/)

---

## 🎨 Features

### 🎯 Core Features
- **Sticky Header Navigation** with smooth scrolling links
- **Hero Section** with an attractive call-to-action (CTA)
- **Dynamic Image Slider** (Swiper.js with fade effect)
- **Responsive Gallery** with a lightbox modal viewer
- **Interactive Price Table** with service emoji icons
- **Ambient Music Player** with a play/pause toggle
- **Google Maps Integration** for location tracking
- **Back to Top Button** for efficient navigation

### 🎬 Visual Enhancements
- **Smooth Animations** using CSS transitions & transforms
- **Premium Gradients** for a sophisticated aesthetic
- **3D Perspective Effects** on emoji icons
- **Drop-shadow Filters** for added depth
- **Glassmorphism Header** with background blur

### 📱 Responsiveness
- **Mobile-First Design** with 4 breakpoints (480px, 768px, 1024px)
- **Touch Gestures** - Swipe navigation on mobile devices
- **Flexible Grid Layouts** using CSS Grid & Flexbox
- **Optimized Images** with lazy loading

### ♿ Accessibility
- **ARIA Labels** with semantic HTML
- **Keyboard Navigation** (Tab, Enter, Arrows, Escape)
- **Screen Reader Support** with roles & descriptions
- **Focus Management** with visible outlines

### ⚡ Performance
- **Deferred Script Loading** for faster rendering
- **CSS Custom Properties** for efficient styling
- **Image Lazy Loading** on scroll
- **Minimal Dependencies** (only Swiper.js + Font Awesome)
